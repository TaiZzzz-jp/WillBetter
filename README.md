# 🌱 Will Better

## 「夢がない」からでも始められる。今日の一歩を応援する。

Will Betterは、夢を持っている人だけではなく、
「やりたいことが分からない」「夢がまだない」という人も
自分の「好き」「気になる」から一歩を踏み出せるようにするアプリです。

夢を決めることをゴールにするのではなく、

**好き → 気になる → 調べる → やってみる → 気づく**

というサイクルを作ることを目指しています。

---

## 💡 このアプリでできること

### 🌱 夢を探す

まだ夢がない人でも大丈夫。

- 好きなことから夢を探す
- 複数の「好き」を組み合わせる
- ランダムで夢を探す
- 気になる職業を探す

など、自分の興味から可能性を見つけられます。

### 🎯 今日の一歩

大きな夢をそのまま目指すのではなく、
「今日できる小さな行動」に変えて取り組みます。

例えば、

> 「ゲームクリエイターになりたい」
>
> ↓
>
> 「ゲームについて15分調べる」

のように、最初の一歩を小さくします。

### ⭐ XP・レベルアップ

行動するとXPを獲得できます。

毎日の小さな行動を積み重ねることで、
レベルが上がり、魚も成長していきます。

### 📖 行動の記録

これまでに、

- 何をしたか
- 何分取り組んだか
- どれだけXPを獲得したか

を記録できます。

---

## 🐟 Will Betterの考え方

夢は最初から決まっていなくてもいい。

「ゲームが好き」
「音楽が好き」
「絵を描くのが好き」
「なんとなく宇宙が気になる」

そんな小さな興味も、夢の種になると考えています。

そして、

**「夢を持つこと」よりも「動いてみること」を大切にする。**

それがWill Betterのコンセプトです。
